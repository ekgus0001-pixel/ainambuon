## 📌 프로젝트 소개 (Overview)

**AI남부ON**은 체성분 분석기 **InBody 280**의 측정 데이터를 시각화하고, 운동생리학적 기준과 노인복지관 현장 프로세스를 결합하여 맞춤형 운동관리 및 전문 리포트를 제공하는 시스템입니다.

현장에서 수기로 작성·대조하던 인바디 결과 확인 과정을 표준화하여, 수검자의 상태에 맞춰 **일반 건강관리(🟢)**, **그룹 운동 권장(🟡)**, **운동처방사 개별상담(🔴)** 대상자를 효율적으로 선별하고 전문 마크다운(MD) 리포트를 즉시 생성합니다.

---

## ✨ 주요 기능 (Key Features)

### 1. 🔍 원본 결과지 대조 & 반응형 시각화 (`inbody280_analyzer.html`)
- **결과지 사진 업로드 & 뷰어**: 인바디 촬영 사진을 업로드하여 1:1로 수치를 대조하며 입력 가능 (확대/축소 지원)
- **정통 인바디 280 규격 뷰**: 체수분, 단백질, 무기질, 체지방량, 골격근량 등 표준 눈금 비율 그래프 실시간 렌더링
- **부위별 근육 분석**: 오른팔, 왼팔, 몸통, 오른다리, 왼다리 5대 부위 발달 상태 시각화

### 2. 📈 C-I-D 체형 모델 & 임상 지표 실시간 계산
- **C-I-D 모델 자동 판정**: 체중-골격근량-체지방량 그래프 패턴을 분석하여 C자형(비만/근육부족), I자형(표준균형), D자형(강인/근육형) 판정
- **대사량 정밀 산출**:
  - **제지방량(FFM)** 기반 정밀 기초대사량(BMR) 계산
  - 활동계수를 반영한 유지대사량(TDEE) 및 감량/증량 목표 칼로리 제안
  - 체중 및 체형 맞춤 1일 단백질 권장 섭취량 자동 계산

### 3. 📝 전문 마크다운(MD) 리포트 자동 생성
- 수치 입력 및 수정 즉시 **원클릭 복사 가능한 마크다운 리포트** 자동 작성
- **포함 내용**: 기본 프로필, 체성분 소견, 비만도/내장지방 평가, 맞춤 영양 가이드, 8주 운동 처방 로드맵
- 클립보드 복사 및 `.md` 파일 다운로드 기능 제공

### 4. 🖨️ A4 결과지 인쇄 최적화
- 불필요한 컨트롤 바를 숨기고 공식 인바디 리포트 양식으로 깔끔하게 출력할 수 있는 인쇄 전용 스타일(Print Media Query) 적용

### 5. ⚡ 원클릭 체형 프리셋
- C형 (비만/근육부족), I형 (표준균형), D형 (이상적 근육형), 마른비만 등 대표 체형 데이터를 원클릭으로 불러와 테스트 가능

## 📐 C-I-D 체형 모델 분류 체계

```text
       [ C자형 ]                 [ I자형 ]                 [ D자형 ]
  체중   ───▶ (높음/표준)     체중   ───▶ (표준)        체중   ───▶ (표준)
골격근   ──▶   (낮음)       골격근   ───▶ (표준)       골격근   ─────▶ (높음)
체지방   ────▶ (높음)       체지방   ───▶ (표준)        체지방   ──▶   (낮음)
  => 비만형 / 근육부족형        => 표준 균형형            => 강인형 / 이상적 근육형
```

- **C자형 (근육 부족/비만형)**: 근육량이 표준 이하이며 체지방이 높은 상태. 점진적 과부하 근력 운동과 단백질 보충 최우선.
- **I자형 (표준 균형형)**: 체중, 근육, 지방이 고르게 분포된 균형 잡힌 상태.
- **D자형 (강인형/근육형)**: 높은 골격근량과 낮은 체지방률을 보유한 이상적인 피트니스 체형.

| 단계 | 관리 구분 | 세부 내용 |
| :---: | :---: | :--- |

## 🚀 실행 및 사용 방법 (Getting Started)

별도의 백엔드 서버나 빌드 과정 없이 웹 브라우저에서 즉시 실행할 수 있습니다.

1. **저장소 복제(Clone)**
   ```bash
   git clone https://github.com/ekgus0001-pixel/ainambuon.git
   cd ainambuon
   ```

2. **애플리케이션 실행**
   - `inbody280_analyzer.html` 파일을 더블 클릭하거나 웹 브라우저(Chrome, Edge 등)로 엽니다.

3. **사용 흐름**
   1. 좌측에서 인바디 결과지 이미지를 업로드합니다.
   2. 성별, 신장, 체중, 골격근량 등 주요 수치를 확인 및 입력합니다.
   3. 실시간으로 갱신되는 체형 판정, 대사량, 그래프를 확인합니다.
   4. 우측 하단의 **[📋 리포트 복사]** 또는 **[💾 MD 파일 다운로드]**를 클릭하여 맞춤 분석 리포트를 활용합니다.
   5. 필요 시 상단의 **[🖨️ A4 결과지 인쇄]** 버튼으로 인쇄하거나 PDF로 저장합니다.
